# Static assets

Vite copies this directory into the production build. `favicon.svg` is an original shop-and-tomato illustration created for Mini Market Manager and covered by the repository MIT license.

The initial game generates its gameplay art and sound in code. Future sprite sheets, icons, and audio files can live here, grouped by purpose. Resolve their URLs using Vite's base path so they work when hosted at `/mini-market-game/`.

Record the source and license of any added third-party asset in `docs/credits.md`.
